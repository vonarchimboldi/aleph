Core Pattern

First respect support and parameter space. For estimator improvement, condition an unbiased estimator on a sufficient statistic; completeness then gives uniqueness.

\[T^*=E[T\mid S],\qquad \operatorname{Var}(T^*)\le\operatorname{Var}(T).\]
Problems 1-5 - Concept Builders
1. Geometric MLE
MLEScore

For iid geometric observations on \(1,2,\ldots\) with mass \(p(1-p)^{x-1}\), find the MLE of \(p\).

Solution

The log-likelihood is \(n\log p+(\sum x_i-n)\log(1-p)\). Solving the score equation gives \(\hat p=n/\sum x_i=1/\bar X\), with boundary behavior checked against \(0<p\le1\).

2. Uniform endpoint MLE
Support-dependent likelihoodBoundary

For iid Uniform\((0,\theta)\), explain why differentiating \(-n\log\theta\) without the support indicator is incomplete.

Solution

The likelihood is \(\theta^{-n}\mathbf1\{\theta\ge X_{(n)}\}\). It decreases only on the feasible parameter set, so its maximum occurs at the boundary \(\hat\theta=X_{(n)}\).

3. Poisson factorization
SufficiencyFactorization

Show that \(S=\sum_iX_i\) is sufficient for iid Poisson\((\lambda)\) data.

Solution

The joint mass equals \(e^{-n\lambda}\lambda^{\sum x_i}/\prod x_i!\). All parameter dependence is through \(S\), while the remaining factor is parameter-free; the factorization theorem proves sufficiency.

4. Bernoulli sufficient count
SufficiencyBinomial

Identify a sufficient statistic for iid Bernoulli\((p)\) observations and its distribution.

Solution

The likelihood is \(p^{\sum x_i}(1-p)^{n-\sum x_i}\), so \(S=\sum X_i\) is sufficient. It has Binomial\((n,p)\) distribution.

5. Bias and MSE
Estimator qualityMSE

An estimator has bias \(2/n\) and variance \(3/n\). Write its MSE and leading asymptotic order.

Solution

MSE equals variance plus squared bias: \(3/n+4/n^2\). Its leading order is \(1/n\), because the variance term dominates the squared bias.

Problems 6-8 - Integration Problems
6. Rao–Blackwellize one observation
Rao–BlackwellBernoulli

For iid Bernoulli\((p)\), start with unbiased \(T=X_1\) and sufficient \(S=\sum_iX_i\). Find \(E[T\mid S]\).

Solution

Given \(S=s\), symmetry makes each coordinate equally likely to contain any of the \(s\) successes. Hence \(E[X_1\mid S=s]=s/n\), so the improved estimator is \(S/n=\bar X\).

7. Variance reduction check
Rao–BlackwellVariance

Compare the variances of \(X_1\) and \(\bar X\) in Problem 6.

Solution

They are \(p(1-p)\) and \(p(1-p)/n\), respectively. Conditioning on the sufficient count removes irrelevant ordering noise and reduces variance for \(n>1\).

8. Lehmann–Scheffé recognition
UMVUECompleteness

State a condition under which an unbiased function of a statistic \(S\) is the unique UMVUE.

Solution

If \(S\) is sufficient and complete for the parameter family, every unbiased estimator that is a measurable function of \(S\) is the unique UMVUE of its expectation.

Problems 9-10 - ISI-Style Challenge
9. Poisson UMVUE
UMVUEPoisson

For iid Poisson\((\lambda)\), use \(S=\sum X_i\) to give the UMVUE of \(e^{-\lambda}\).

Solution

The indicator \(I\{X_1=0\}\) is unbiased for \(e^{-\lambda}\). Given \(S=s\), \(X_1\mid S=s\sim\operatorname{Bin}(s,1/n)\), so the conditional probability of zero is \((1-1/n)^s\), the UMVUE.

10. Nonunique uniform-location MLE
MLE setSupport

For iid Uniform\((\theta,\theta+2)\), derive the full MLE set and its nonemptiness condition.

Solution

All data must satisfy \(X_{(n)}-2\le\theta\le X_{(1)}\). The likelihood is constant on this interval, so every point there is an MLE. The interval is nonempty exactly when the sample range is at most 2.
