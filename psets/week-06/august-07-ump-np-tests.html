Core Pattern

Fix the likelihood-ratio direction before calibrating the cutoff under the null. For one-sided composite tests, use the null boundary and a monotone-likelihood-ratio statistic.

\[\text{evidence order}\to\text{rejection tail}\to P_{H_0}(\text{reject})=\alpha\to\text{power}.\]
Problems 1-5 - Concept Builders
1. Normal sample mean direction
NP directionNormal

For iid \(N(\mu,1)\), test \(\mu=0\) against \(\mu=1\). Which statistic and tail reject?

Solution

The likelihood ratio increases with \(\sum X_i\), equivalently \(\bar X\). Large sample means favor \(\mu=1\), so reject in the upper tail.

2. Exact normal cutoff
Size calibrationQuantile

For the preceding test, give the level-\(\alpha\) cutoff in terms of \(\bar X\).

Solution

Under the null, \(\sqrt n\bar X\sim N(0,1)\). Reject when \(\sqrt n\bar X>z_{1-\alpha}\), or \(\bar X>z_{1-\alpha}/\sqrt n\).

3. Binomial MLR
MLRBinomial

For \(X\sim\operatorname{Bin}(n,p)\), explain why larger \(X\) favors larger \(p\).

Solution

For \(p_1>p_0\), the likelihood ratio is a positive constant times \([p_1(1-p_0)/(p_0(1-p_1))]^X\), whose base exceeds one. Thus it increases in \(X\).

4. Randomization equation
Exact sizeDiscrete test

If a test rejects above \(c\) and randomizes at \(c\), write the equation determining randomization probability \(\gamma\).

Solution

Exact size requires \(P_0(T>c)+\gamma P_0(T=c)=\alpha\). Therefore \(\gamma=[\alpha-P_0(T>c)]/P_0(T=c)\), when this lies in \([0,1]\).

5. Exponential-rate tail
Likelihood ratioExponential

For iid Exp\((\lambda)\), which tail of \(\sum X_i\) favors \(\lambda_1>\lambda_0\)?

Solution

The ratio contains \(e^{-(\lambda_1-\lambda_0)\sum x_i}\), so it decreases in the sum. A larger rate produces shorter lifetimes; reject for a small sum.

Problems 6-8 - Integration Problems
6. Composite normal UMP test
UMPBoundary calibration

For iid \(N(\mu,1)\), test \(H_0:\mu\le0\) against \(H_1:\mu>0\). Give the UMP level-\(\alpha\) rule.

Solution

The family has MLR in \(\sum X_i\). The largest null rejection probability occurs at boundary \(\mu=0\), so reject when \(\sqrt n\bar X>z_{1-\alpha}\).

7. Gamma transformed cutoff
Null distributionGamma

Under \(H_0:\lambda=\lambda_0\), identify the distribution used to calibrate a lower-tail test based on \(S=\sum_iX_i\) for exponential data.

Solution

The sum is Gamma with shape \(n\) and rate \(\lambda_0\). Choose \(c\) satisfying \(P_{lambda_0}(S\le c)=\alpha\); equivalently, \(2\lambda_0S\sim\chi^2_{2n}\).

8. Power monotonicity
PowerOne-sided test

For the upper-tail normal test in Problem 6, show that power increases with \(\mu\).

Solution

Power is \(1-\Phi(z_{1-\alpha}-\sqrt n\mu)\). As \(\mu\) rises, the argument of \(\Phi\) falls, so the upper-tail probability increases.

Problems 9-10 - ISI-Style Challenge
9. Uniform endpoint NP structure
Support conflictNP test

For iid Uniform\((0,\theta)\), test \(\theta=1\) against \(\theta=2\). Describe the likelihood-ratio ordering using \(M=X_{(n)}\).

Solution

Samples with \(M>1\) are impossible under the null and must be rejected. On \(M\le1\), the likelihood ratio is constant, so any additional rejection needed for exact size must randomize over that region.

10. Why two-sided UMP fails
No UMPConflicting tails

Explain the obstruction to a UMP test of \(N(\mu,1)\), \(H_0:\mu=0\) versus \(H_1:\mu\ne0\).

Solution

Positive alternatives rank large observations as strongest evidence, while negative alternatives rank small observations as strongest. No single level-\(\alpha\) rejection region can be most powerful in both conflicting directions.
