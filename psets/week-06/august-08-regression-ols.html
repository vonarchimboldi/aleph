Core Pattern: Regression Repair

Start from the objective, differentiate once, and interpret the normal equations geometrically. Keep unrestricted and constrained orthogonality separate.

\[X^T(y-X\hat\beta)=0,\qquad \hat y=P_Xy,\qquad e=(I-P_X)y.\]
Problems 1-5 - Repair and Concept Builders
1. Centered simple-regression slope
Regression repairSlope

For data \((x_i,y_i)\), write the OLS slope and intercept using centered sums.

Solution

The slope is \(\hat\beta_1=\sum(x_i-\bar x)(y_i-\bar y)/\sum(x_i-\bar x)^2\), provided the denominator is positive. The intercept is \(\hat\beta_0=\bar y-\hat\beta_1\bar x\).

2. Residual sums with an intercept
Regression repairOrthogonality

Show that OLS residuals sum to zero when the design includes an intercept.

Solution

The intercept column is the all-ones vector. The normal equations give \(X^Te=0\); its intercept coordinate is \(\mathbf1^Te=\sum_ie_i=0\).

3. Residuals versus fitted values
Regression repairProjection

Prove \(\hat y^Te=0\) for unrestricted OLS.

Solution

Because \(\hat y=X\hat\beta\) lies in the column space of \(X\), \(\hat y^Te=\hat\beta^TX^Te=0\) by the normal equations.

4. Normal equations from differentiation
Regression repairMatrix calculus

Differentiate \(L(\beta)=\|y-X\beta\|^2\) and derive the normal equations.

Solution

Expanding gives \(y^Ty-2\beta^TX^Ty+\beta^TX^TX\beta\). Its gradient is \(-2X^Ty+2X^TX\beta\). Setting this to zero yields \(X^TX\hat\beta=X^Ty\).

5. Rank and uniqueness
Regression repairRank

When is the OLS coefficient vector unique, and what remains unique if coefficients are not?

Solution

Coefficients are unique when \(X\) has full column rank, so \(X^TX\) is invertible. Even under rank deficiency, the projection \(\hat y\) onto \(\operatorname{col}(X)\) is unique.

Problems 6-8 - Application and Bridge Problems
6. Rescaling a predictor
InvarianceSimple regression

If \(x_i'=a+bx_i\) with \(b\ne0\), express the new slope and explain what happens to fitted values.

Solution

Centered predictors scale by \(b\), so the new slope is \(\hat\beta_1/b\); the intercept adjusts for \(a\). The span of intercept and predictor is unchanged, so fitted values and residuals are identical.

7. Non-Gaussian errors
AssumptionsOLS

Under \(y=X\beta+\varepsilon\), what do \(E[\varepsilon\mid X]=0\) and \(\operatorname{Var}(\varepsilon\mid X)=\sigma^2I\) give without normality?

Solution

With full column rank, OLS is conditionally unbiased and has covariance \(\sigma^2(X^TX)^{-1}\). Normality is not needed for these moment results, though it supports exact finite-sample distributional inference.

8. One linear constraint
Constrained OLSLagrange equations

Minimize \(\|y-X\beta\|^2\) subject to \(r^T\beta=c\). Write the first-order equations.

Solution

Using multiplier \(\lambda\), stationarity gives \(X^TX\beta+r\lambda=X^Ty\), together with \(r^T\beta=c\). The residual need not be orthogonal to every design column because feasible coefficient movements are restricted.

Problems 9-10 - ISI-Style Challenge and Synthesis
9. Constrained estimator formula
Constrained OLSSynthesis

Assume \(X^TX\) is invertible. Derive the constrained estimator for \(R\beta=r\) from unrestricted \(\hat\beta\).

Solution

Solving the block first-order system yields \(\hat\beta_c=\hat\beta-(X^TX)^{-1}R^T[R(X^TX)^{-1}R^T]^{-1}(R\hat\beta-r)\). The correction is the metric projection onto the affine constraint set.

10. Sum-of-squares decomposition
Regression repairANOVA identity

With an intercept, prove \(\sum(y_i-\bar y)^2=\sum(\hat y_i-\bar y)^2+\sum e_i^2\).

Solution

Write \(y-\bar y\mathbf1=(\hat y-\bar y\mathbf1)+e\). The fitted centered vector lies in the design space and is orthogonal to \(e\), so the squared norm splits by Pythagoras.
