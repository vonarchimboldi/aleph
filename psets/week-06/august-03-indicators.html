Core Pattern

Define one indicator for each countable object. Use linearity for the mean; for variance, separate individual variances from pairwise covariances.

\[X=\sum_i I_i,\quad E[X]=\sum_iP(I_i=1),\quad \operatorname{Var}(X)=\sum_i\operatorname{Var}(I_i)+2\sum_{i<j}\operatorname{Cov}(I_i,I_j).\]
Problems 1-5 - Concept Builders
1. Fixed points revisited
IndicatorSymmetry

A uniform random permutation of \(n\) objects has \(X\) fixed points. Find \(E[X]\).

Solution

Let \(I_i\) record that object \(i\) is fixed. Symmetry gives \(P(I_i=1)=1/n\). Therefore \(E[X]=\sum_iE[I_i]=n(1/n)=1\); independence is unnecessary.

2. Empty boxes
IndicatorOccupancy

Throw \(m\) balls independently and uniformly into \(n\) boxes. Find the expected number of empty boxes.

Solution

For box \(j\), let \(I_j=1\) when no ball enters it. Each ball misses it with probability \(1-1/n\), so \(E[I_j]=(1-1/n)^m\). The answer is \(n(1-1/n)^m\).

3. Adjacent successes
IndicatorOverlap

In \(n\) independent Bernoulli(\(p\)) trials, let \(X\) count adjacent pairs \(11\). Find \(E[X]\).

Solution

There are \(n-1\) adjacent positions. If \(I_i\) records successes at \(i,i+1\), then \(E[I_i]=p^2\). Thus \(E[X]=(n-1)p^2\), despite overlap between neighboring indicators.

4. Distinct birthdays
IndicatorComplement

For \(m\) independent uniform birthdays among \(d\) days, find the expected number of represented days.

Solution

Let \(I_j\) indicate that day \(j\) appears. Its complement is that all \(m\) birthdays miss the day, with probability \((1-1/d)^m\). Hence the expectation is \(d[1-(1-1/d)^m]\).

5. Graph triangles under sparse scaling
IndicatorRandom graph

In \(G(n,c/n)\), derive the expected number of triangles and find its limit as \(n\to\infty\).

Solution

There is one indicator per vertex triple, with success probability \((c/n)^3\). Hence \(E[X]=\binom n3(c/n)^3\), which tends to \(c^3/6\).

Problems 6-8 - Integration Problems
6. Variance of fixed points
Pair productsCovariance

For the fixed-point count in Problem 1, compute \(\operatorname{Var}(X)\) for \(n\ge2\).

Solution

Here \(E[I_i]=1/n\) and for \(i\ne j\), \(E[I_iI_j]=(n-2)!/n!=1/[n(n-1)]\). Expanding \(E[X^2]\) gives \(1+1=2\), so \(\operatorname{Var}(X)=2-1^2=1\).

7. Isolated vertices at logarithmic scale
IndicatorRandom graph

In \(G(n,(\log n+c)/n)\), derive the expected number of isolated vertices and find its limit.

Solution

The expectation is \(n[1-(\log n+c)/n]^{n-1}\). Using \((1-a_n/n)^n\sim e^{-a_n}\), this tends to \(e^{-c}\).

8. Exactly one ball
IndicatorBinomial marginal

In the occupancy model with \(m\) balls and \(n\) boxes, find the expected number of boxes containing exactly one ball.

Solution

A fixed box receives exactly one ball with probability \(\binom m1(1/n)(1-1/n)^{m-1}\). Multiply by \(n\): the expectation is \(m(1-1/n)^{m-1}\).

Problems 9-10 - ISI-Style Challenge
9. Runs of three
Pair dependenceVariance

In \(n\) fair coin tosses, let \(X\) count starting positions of HHH. Set up \(\operatorname{Var}(X)\), identifying which indicator pairs have nonzero covariance.

Solution

There are \(n-2\) indicators with mean \(1/8\). Disjoint triples are independent. Starts one apart have joint probability \(1/16\); starts two apart have joint probability \(1/32\). Insert these overlaps into the pair-covariance expansion.

10. Singleton labels in sampling
IndicatorMultinomial

Draw \(m\) times independently from \(n\) equally likely labels. Let \(S\) be the number of labels observed exactly once. Find \(E[S]\) and its limit when \(m=n\to\infty\), divided by \(n\).

Solution

The same singleton calculation gives \(E[S]=m(1-1/n)^{m-1}\). With \(m=n\), \(E[S]/n=(1-1/n)^{n-1}\to e^{-1}\).
