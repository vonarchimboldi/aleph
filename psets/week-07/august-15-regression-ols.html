Core Pattern

Separate geometry from stochastic assumptions: normal equations define OLS, residuals are orthogonal to the design space, and each linear constraint changes the projection geometry; unbiasedness and variance claims require conditions on the errors.

\[\hat\beta=(X^TX)^{-1}X^Ty,\quad H=X(X^TX)^{-1}X^T,\quad e=(I-H)y.\]
Problems 1-5 - Concept Builders
1. Hat-matrix symmetry

Show the full-rank hat matrix (H) is symmetric and idempotent.

Solution

Transpose gives (H^T=H); multiplication gives (H^2=X(X^TX)^{-1}X^TX(X^TX)^{-1}X^T=H).

2. Leverage sum

Show the leverages (h_{ii}) sum to the number (p) of columns of (X).

Solution

(sum h_{ii}=tr(H)=tr((X^TX)^{-1}X^TX)=tr(I_p)=p).

3. Intercept-implied residual balance

When the design contains an intercept, prove residuals sum to zero.

Solution

The all-ones vector is a column of (X). Normal equations (X^Te=0) therefore include (1^Te=0).

4. OLS unbiasedness

Under (y=X\beta+\varepsilon), state the condition needed for (E[\hat\beta\mid X]=\beta).

Solution

Require (E[\varepsilon\mid X]=0); substitute into (hat\beta=\beta+(X^TX)^{-1}X^T\varepsilon).

5. Homoskedastic variance

If (Var(\varepsilon\mid X)=\sigma^2I), find (Var(\hat\beta\mid X)).

Solution

(sigma^2(X^TX)^{-1}).

Problems 6-8 - Integration Problems
6. Weighted least squares

If (Var(\varepsilon\mid X)=\sigma^2W^{-1}), derive the WLS normal equations and estimator.

Solution

Minimize ((y-X\beta)^TW(y-X\beta)): (X^TWX\hat\beta=X^TWy), so (hat\beta=(X^TWX)^{-1}X^TWy).

7. Omitted-variable bias

The true model is (y=\beta_0+\beta_1x+\gamma z+\varepsilon). If (z) is omitted, express the population slope on (x).

Solution

(Cov(x,y)/Var(x)=\beta_1+\gamma Cov(x,z)/Var(x)).

8. High leverage

Explain why a point with unusual predictor values can have high leverage even with a small residual.

Solution

Leverage depends only on (X), via (h_{ii}=x_i^T(X^TX)^{-1}x_i); residual size also depends on the response.

Problems 9-10 - ISI-Style Challenge
9. Heteroskedastic sandwich

If (Var(\varepsilon\mid X)=\Omega), derive (Var(\hat\beta\mid X)).

Solution

((X^TX)^{-1}X^T\Omega X(X^TX)^{-1}), the population sandwich form.

10. Leave-one-out residual

State the relationship between the ordinary residual (e_i), leverage (h_{ii}), and the leave-one-out prediction residual.

Solution

The deleted/leave-one-out residual is (e_i/(1-h_{ii})); high leverage magnifies the discrepancy.
