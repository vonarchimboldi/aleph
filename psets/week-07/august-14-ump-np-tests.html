Core Pattern

Order outcomes by likelihood ratio, calibrate probability under the least favorable null boundary, then compute power under alternatives.

\[\sup_{\theta\in H_0}P_\theta(\text{reject})\le\alpha.\]
Problems 1-5 - Concept Builders
1. Normal upper-tail test

For (X_i\sim N(\mu,\sigma^2)), known (sigma), give the level-(alpha) test of (H_0:\mu\le\mu_0) versus (H_1:\mu>\mu_0).

Solution

Reject when (ar X>\mu_0+z_{1-\alpha}\sigma/\sqrt n).

2. Power function

Compute the power of the test in Problem 1 at (mu).

Solution

(pi(\mu)=1-\Phi(z_{1-\alpha}-(\mu-\mu_0)\sqrt n/\sigma)).

3. Binomial randomization

If (X\sim Bin(n,p_0)) and no integer cutoff gives exact size (alpha), state how to randomize.

Solution

Choose (c) with (P(X>c)<\alpha\le P(X\ge c)); reject above (c) and at (c) with (gamma=[\alpha-P(X>c)]/P(X=c)).

4. Exponential rejection direction

For exponential rate (lambda), which direction of (S=\sum X_i) supports (lambda>\lambda_0)?

Solution

Larger rates create smaller waiting times, so reject for small (S).

5. One-sided p-value

Under Problem 1, write the p-value for observed (ar x).

Solution

(1-\Phi((\bar x-\mu_0)\sqrt n/\sigma)).

Problems 6-8 - Integration Problems
6. MLR to UMP

Explain why monotone likelihood ratio in statistic (T) yields a UMP upper-tail test for a one-sided alternative.

Solution

NP gives the same upper-tail ordering for every simple alternative beyond the null boundary; boundary calibration controls the whole composite null.

7. Confidence-test duality

Invert the normal tests of (H_0:\mu=\mu_0) to obtain a (1-\alpha) confidence interval.

Solution

Values not rejected satisfy (|\bar X-\mu_0|\le z_{1-\alpha/2}\sigma/\sqrt n), yielding (ar X\pm z_{1-\alpha/2}\sigma/\sqrt n).

8. NP likelihood ratio

For one observation from (N(\mu,1)), compare (H_0:\mu=0) with (H_1:\mu=a>0) and simplify the likelihood ratio.

Solution

(f_a(x)/f_0(x)=e^{ax-a^2/2}), increasing in (x), so the most powerful test rejects for large (X).

Problems 9-10 - ISI-Style Challenge
9. Conflicting most-powerful tails

Explain why no nontrivial level-(alpha) UMP test generally exists for (H_0:\mu=0) versus (H_1:\mu\ne0) in the normal model.

Solution

NP demands an upper-tail region for each positive alternative and a lower-tail region for each negative alternative. No single size-(alpha) region is most powerful for both directions.

10. Least favorable boundary

For a family stochastically increasing in ( heta), justify calibrating an upper-tail test of (H_0:\theta\le\theta_0) at ( heta_0).

Solution

Upper-tail rejection probability increases with ( heta), so its supremum over the null occurs at the boundary ( heta_0).
