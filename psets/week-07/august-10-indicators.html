Core Pattern

Write the count as a sum of indicators. Linearity gives the mean without independence; pair probabilities determine variance and second-moment bounds.

\[X=\sum_i I_i,\quad E[X^2]=E[X]+2\sum_{i<j}P(I_i=I_j=1).\]
Problems 1-5 - Concept Builders
1. Missing coupons

After (m) uniform draws from (n) coupon types, find the expected number (M) of missing types.

Solution

For type (j), (P(I_j=1)=(1-1/n)^m). Thus (E[M]=n(1-1/n)^m).

2. Matching positions

Two independent uniform permutations of ([n]) are compared positionwise. Find the expected number of matches.

Solution

Each position matches with probability (1/n), so the expectation is (n/n=1).

3. Inversions

Find the expected number of inversions in a uniform random permutation of ([n]).

Solution

For every pair (i<j), the relative order is reversed with probability (1/2). Hence (E[X]=\binom n2/2=n(n-1)/4).

4. Empty urn covariance

In the (m)-ball, (n)-box model, compute (P(I_i=I_j=1)) for two specified boxes being empty and determine the covariance sign.

Solution

The joint probability is ((1-2/n)^m). Since this is smaller than ((1-1/n)^{2m}), the empty-box indicators have negative covariance.

5. Four-cycles in a random graph

In (G(n,p)), find the expected number of unoriented 4-cycles.

Solution

Each four-vertex set has (3) distinct cycles, each present with probability (p^4). Thus (E[X]=3\binom n4p^4).

Problems 6-8 - Integration Problems
6. Coupon-pair second moment

For the missing-coupon count (M), derive (E[M^2]).

Solution

Use (M^2=\sum I_i+2\sum_{i<j}I_iI_j): (E[M^2]=n(1-1/n)^m+n(n-1)(1-2/n)^m).

7. Collision count

For (m) iid uniform labels from ([n]), let (C) count equal unordered pairs. Find (E[C]) and identify when it stays order one.

Solution

There are (inom m2) pairs, each equal with probability (1/n). Thus (E[C]=\binom m2/n), order one when (m) is order (sqrt n).

8. Runs with wraparound

In (n) cyclic Bernoulli((p)) trials, find the expected number of cyclic runs (111).

Solution

There are (n) cyclic starting positions and each triple succeeds with probability (p^3), so (E[X]=np^3).

Problems 9-10 - ISI-Style Challenge
9. Existence by the second moment

Let (Xge0) be an integer-valued count. Prove (P(X>0)\ge E[X]^2/E[X^2]), and explain why bounded (E[X^2]/E[X]^2) prevents disappearance.

Solution

Cauchy–Schwarz gives (E[X]=E[X1_{X>0}]\le(E[X^2]P(X>0))^{1/2}). Rearranging proves the bound.

10. Isolated edges

In (G(n,p)), find the expected number of components consisting of exactly one edge and its two endpoints.

Solution

Choose the endpoints, require their edge, and forbid the (2(n-2)) edges from them to other vertices: (E[X]=\binom n2p(1-p)^{2(n-2)}).
