Core Pattern

Order outcomes by evidence for the alternative, then spend size under the null on the strongest evidence first.

\[\frac{L(\theta_1;x)}{L(\theta_0;x)}>k,\qquad P_{\theta_0}(\text{reject})=\alpha.\]
Problems 1-5 - Concept Builders
1. Normal upper-tail direction
Week 5Diagnostic

For one \(X\sim N(\mu,1)\), test \(H_0:\mu=0\) against \(H_1:\mu=1\). Which tail rejects?

Solution

The likelihood ratio is \(e^{x-1/2}\), increasing in \(x\). Reject for large \(X\).

2. Size calibration
Week 5Diagnostic

Under \(H_0\), \(X\sim N(0,1)\). Find \(c\) so rejection \(X>c\) has size \(0.05\).

Solution

Choose \(c=z_{0.95}\), approximately \(1.645\).

3. Power of normal test
Week 5Diagnostic

For the previous rejection rule, find power at \(\mu=1\).

Solution

Under \(\mu=1\), power is \(P(X>1.645)=1-\Phi(0.645)\).

4. Binomial evidence
Week 5Diagnostic

For \(X\sim\operatorname{Bin}(n,p)\), test \(p=p_0\) against \(p=p_1>p_0\). Is the likelihood ratio increasing or decreasing in \(X\)?

Solution

Its successive ratio exceeds one because \(p_1>p_0\). Evidence for the alternative grows with \(X\), so reject for large counts.

5. Exact-size randomization
Week 5Diagnostic

If \(P_0(X>c)=0.03\) and \(P_0(X=c)=0.04\), what randomization probability at \(X=c\) gives size \(0.05\)?

Solution

Solve \(0.03+\gamma(0.04)=0.05\), giving \(\gamma=1/2\).

Problems 6-8 - Integration Problems
6. Exponential rate direction
Week 5Diagnostic

For iid exponential data, test rate \(\lambda_0\) against \(\lambda_1>\lambda_0\). In which direction should \(\sum X_i\) reject?

Solution

The ratio is proportional to \(e^{-(\lambda_1-\lambda_0)\sum x_i}\), decreasing in the sum. Larger rate means shorter observations, so reject for small \(\sum X_i\).

7. Uniform endpoint test
Week 5Diagnostic

For iid \(U(0,\theta)\), test \(\theta=1\) against \(\theta=2\). Which observations make the null impossible?

Solution

If \(X_{(n)}>1\), the null density is zero while the alternative can assign positive density. Such samples must be in the rejection region.

8. One-sided UMP cue
Week 5Diagnostic

Why does a monotone likelihood ratio in statistic \(T\) support one common level-\(\alpha\) rejection rule for alternatives \(\theta>\theta_0\)?

Solution

Every larger alternative ranks samples in the same order of evidence through \(T\). The upper-tail rule calibrated at the null boundary is therefore most powerful for each such alternative.

Problems 9-10 - ISI-Style Challenge
9. Poisson randomized test
Week 5Diagnostic

Under \(H_0\), \(X\sim\operatorname{Poisson}(1)\). A test rejects for \(X\ge3\) and randomizes at \(X=2\). Express the randomization probability for exact size \(\alpha\).

Solution

\(\gamma=[\alpha-P_0(X\ge3)]/P_0(X=2)\), provided this lies in \([0,1]\). Here \(P_0(X=2)=e^{-1}/2\).

10. No common two-sided tail
Week 5Diagnostic

Explain why testing \(N(\mu,1)\), \(H_0:\mu=0\) against \(\mu\ne0\), is not solved by the same one-sided UMP argument.

Solution

Positive alternatives favor large \(X\), while negative alternatives favor small \(X\). The evidence order conflicts, so no single one-sided tail is most powerful for both directions.
