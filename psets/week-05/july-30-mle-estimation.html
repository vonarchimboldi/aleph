Problems 1-5 - Concept Builders
1. Bernoulli MLE
Week 5Diagnostic

For iid Bernoulli(\(p\)) data with \(s\) successes in \(n\) trials, find the MLE.

Solution

The likelihood is \(p^s(1-p)^{n-s}\). The interior score gives \(\hat p=s/n\), including boundary values when \(s=0\) or \(n\).

2. Exponential rate MLE
Week 5Diagnostic

For iid exponential observations with rate \(\lambda\), find the MLE.

Solution

\(\ell=n\log\lambda-\lambda\sum x_i\). Setting \(n/\lambda-\sum x_i=0\) gives \(\hat\lambda=n/\sum x_i=1/\bar X\).

3. Uniform endpoint support
Week 5Diagnostic

For iid \(U(0,\theta)\), write the likelihood and find the MLE.

Solution

\(L(\theta)=\theta^{-n}\mathbf1\{\theta\ge X_{(n)}\}\). It decreases on its allowed region, so \(\hat\theta=X_{(n)}\).

4. Shifted exponential boundary
Week 5Diagnostic

Data have density \(e^{-(x-\theta)}\mathbf1\{x\ge\theta\}\). Find the MLE of \(\theta\).

Solution

The likelihood is proportional to \(e^{n\theta}\mathbf1\{\theta\le X_{(1)}\}\), increasing up to the boundary. Thus \(\hat\theta=X_{(1)}\).

5. Bias correction
Week 5Diagnostic

For \(U(0,\theta)\), \(E[X_{(n)}]=n\theta/(n+1)\). Give an unbiased estimator based on the maximum.

Solution

Multiply by \((n+1)/n\): \(\tilde\theta=(n+1)X_{(n)}/n\).

Problems 6-8 - Integration Problems
6. Normal mean under constraint
Week 5Diagnostic

For iid \(N(\mu,\sigma^2)\) with known \(\sigma^2\) and constraint \(\mu\ge0\), find the MLE.

Solution

The unrestricted MLE is \(\bar X\). Projection onto \([0,\infty)\) gives \(\hat\mu=\max(0,\bar X)\).

7. MSE comparison
Week 5Diagnostic

Estimator \(T_1\) is unbiased with variance 9. Estimator \(T_2\) has bias 1 and variance 4. Which has lower MSE?

Solution

\(\operatorname{MSE}(T_1)=9\). For \(T_2\), MSE is \(4+1^2=5\), so \(T_2\) is better by MSE.

8. Factorization sufficiency
Week 5Diagnostic

For Poisson(\(\lambda\)) data, identify a sufficient statistic using factorization.

Solution

The joint mass is \(e^{-n\lambda}\lambda^{\sum x_i}/\prod x_i!\). Parameter dependence is only through \(\sum X_i\), so that sum is sufficient.

Problems 9-10 - ISI-Style Challenge
9. Pareto scale boundary
Week 5Diagnostic

For density \(f_\theta(x)=\alpha\theta^\alpha x^{-\alpha-1}\mathbf1\{x\ge\theta\}\), with known \(\alpha\), find the MLE of \(\theta\).

Solution

The likelihood is proportional to \(\theta^{n\alpha}\mathbf1\{\theta\le X_{(1)}\}\), increasing in the allowed region. Hence \(\hat\theta=X_{(1)}\).

10. Two-sided uniform location
Week 5Diagnostic

Data are iid uniform on \([\theta-1,\theta+1]\). Describe the set of MLEs.

Solution

All data must satisfy \(X_{(n)}-1\le\theta\le X_{(1)}+1\). The likelihood is constant on this interval, so every point in it is an MLE, provided it is nonempty.
