Core Pattern

Choose the smallest event whose indicator directly contributes one unit to the target count, then use linearity of expectation.

\[X=\sum_\alpha I_\alpha,\quad E[X]=\sum_\alpha P(I_\alpha=1),\quad E[X(X-1)]=\sum_{\alpha\ne\beta}P(I_\alpha I_\beta=1).\]

Problems 1-5 - Concept Builders
1. Occupied boxes
Week 5Diagnostic

\(m\) balls independently choose one of \(n\) boxes uniformly. Find the expected number of occupied boxes.

Solution

Let \(I_j\) mark box \(j\) occupied. Its empty probability is \((1-1/n)^m\). Thus \(E[X]=n[1-(1-1/n)^m]\).

2. Graph triangles
Week 5Diagnostic

In \(G(n,p)\), find the expected number of triangles.

Solution

Index unordered triples. Each becomes a triangle when its three edges occur, with probability \(p^3\). Hence \(E[X]=\binom n3p^3\).

3. Coupon types seen once
Week 5Diagnostic

After \(m\) uniform draws from \(n\) coupon types, find the expected number of types seen exactly once.

Solution

A fixed type appears once with probability \(m(1/n)(1-1/n)^{m-1}\). Multiply by \(n\): \(E[X]=m(1-1/n)^{m-1}\).

4. Inversions
Week 5Diagnostic

Find the expected inversion count in a uniform random permutation of \(1,\ldots,n\).

Solution

For each pair \(i<j\), mark whether \(i\) appears after \(j\). This has probability \(1/2\). Therefore \(E[X]=\binom n2/2=n(n-1)/4\).

5. Empty-box pair
Week 5Diagnostic

In the allocation of \(m\) balls to \(n\) boxes, what is the probability that two specified boxes are both empty?

Solution

Every ball must avoid both boxes, independently. The probability is \((1-2/n)^m\).

Problems 6-8 - Integration Problems
6. Variance of empty boxes
Week 5Diagnostic

Let \(X\) count empty boxes after \(m\) uniform allocations to \(n\) boxes. Express \(\operatorname{Var}(X)\).

Solution

Put \(a=(1-1/n)^m\), \(b=(1-2/n)^m\). Then \(E[X]=na\), \(E[X(X-1)]=n(n-1)b\), so \(\operatorname{Var}(X)=na+n(n-1)b-n^2a^2\).

7. Conditional random sum
Week 5Diagnostic

Given \(N\), \(X=\sum_{i=1}^N I_i\), where the \(I_i\) are Bernoulli(\(p\)). If \(E[N]=\mu\) and \(\operatorname{Var}(N)=\tau^2\), find \(E[X]\) and \(\operatorname{Var}(X)\).

Solution

\(E[X\mid N]=Np\), \(\operatorname{Var}(X\mid N)=Np(1-p)\). Tower and total variance give \(E[X]=p\mu\) and \(\operatorname{Var}(X)=p(1-p)\mu+p^2\tau^2\).

8. Isolated graph vertices
Week 5Diagnostic

In \(G(n,p)\), find the expected number of isolated vertices.

Solution

A fixed vertex has \(n-1\) incident edges, all absent with probability \((1-p)^{n-1}\). Thus \(E[X]=n(1-p)^{n-1}\).

Problems 9-10 - ISI-Style Challenge
9. Adjacent fixed points
Week 5Diagnostic

For a random permutation, let \(X\) count \(i<n\) such that both \(i\) and \(i+1\) are fixed. Find \(E[X]\).

Solution

A specified adjacent pair is fixed with probability \((n-2)!/n!=1/[n(n-1)]\). There are \(n-1\) pairs, so \(E[X]=1/n\).

10. Disjoint graph edges
Week 5Diagnostic

In \(G(n,p)\), let \(X\) count unordered pairs of vertex-disjoint present edges. Find \(E[X]\).

Solution

Choose four vertices, then one of their three perfect matchings. Both selected edges occur with probability \(p^2\). Hence \(E[X]=3\binom n4p^2\).
