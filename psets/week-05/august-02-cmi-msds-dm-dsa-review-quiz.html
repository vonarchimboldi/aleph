MCQ - Discrete Math: Asymptotics

MCQAsymptotics

  2. \(n^{10}=o(1.01^n)\).

  4. \(n\log n=\Theta(n)\).

MCQ - Discrete Math: Tail Bounds
4. Use only the information given
MCQMarkov / Chebyshev

  1. \(P(X\ge50)\le1/5\) by Markov.

5. A union bound needs no independence
MCQUnion bound

Events \(A_1,\ldots,A_{20}\) satisfy \(P(A_i)\le0.01\). Which statements are guaranteed?

  1. \(P(\bigcup_i A_i)\le0.20\).
  2. \(P(\bigcap_i A_i^c)\ge0.80\).
  3. The events must be independent.
  4. \(P(\bigcup_i A_i)=0.20\).

MCQChernoff bound

  3. It uses only nonnegativity and the mean, exactly like Markov.
  4. Independence is part of the usual hypothesis.

8. Divisibility and cancellation
MCQCongruences

Identify every valid claim about congruence operations and greatest common divisors.

  1. If \(a\equiv b\pmod m\), then \(a+c\equiv b+c\pmod m\).
  2. From \(6x\equiv6y\pmod{15}\), one may conclude \(x\equiv y\pmod{15}\).

MCQFull / complete trees

Select every definition or node-count formula that correctly describes the named binary-tree family.

MCQDFS traversals

MCQReconstruction

  1. Preorder plus inorder uniquely determines a binary tree.

13. Level-order queue invariant
MCQBFS queue

15. Shape controls height cost
MCQTree complexity

A tree algorithm does \(O(1)\) work per visited node. A root-to-leaf search visits one child at each level. Which statements are correct?
