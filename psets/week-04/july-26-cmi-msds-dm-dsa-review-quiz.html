MCQ - Discrete Math: Generating-Function Modeling
1. Coins recorded by a generating function
MCQGenerating functions

A collection may contain any number of \(1\)-rupee coins and any number of \(2\)-rupee coins. Which statements about \(F(x)=1/((1-x)(1-x^2))\) are correct? Select all correct options.

  1. \([x^6]F(x)=4\).
  2. \([x^6]F(x)\) counts ordered sequences of \(1\)- and \(2\)-rupee coins with total value \(6\).
  3. \([x^6]F(x)\) is the number of nonnegative integer solutions of \(a+2b=6\).
  4. Replacing \(1/(1-x^2)\) by \(1+x^2+x^4\) leaves the coefficient of \(x^6\) unchanged.

MCQRational OGF

MCQ - DSA: Set, Map, and Dictionary Semantics
9. Dictionary updates
MCQDictionary trace

  2. The final key set is \(\{a,b,c\}\).

10. Set operations after a trace
MCQSet semantics

Start with empty \(S\). Execute \(add(4),add(1),add(4),remove(1),add(2)\). Let \(T=\{2,4,6\}\). Which statements are true?

  1. \(S=\{2,4\}\)
  2. \(|S|=3\)
  3. \(S\cup T=\{2,4,6\}\)
  4. The symmetric difference of \(S,T\) is \(\{6\}\).
11. Return values versus set state
MCQSet API

A set starts as \(S=\{2,5\}\). \(add(x)\) returns true exactly when \(x\) was absent and inserted; \(remove(x)\) returns true exactly when \(x\) was present and removed; \(contains(x)\) does not mutate. Execute \(add(5),remove(2),contains(2),add(2)\). Which statements are true?

  1. The first call returns false.
  2. The second returns true.
  3. The third changes the set.
  4. The final set is \(\{2,5\}\).
