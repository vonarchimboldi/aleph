Core Pattern

Write the likelihood with support first. Use score equations only for regular interior problems; check boundaries and estimator quality separately, including sufficiency and UMVUE comparisons.

\[I_n(\theta)=nI_1(\theta),\qquad Var(\hat\theta)\gtrsim I_n(\theta)^{-1}.\]
Problems 1-5 - Concept Builders
1. Bernoulli information

Find the Fisher information in one Bernoulli((p)) observation.

Solution

The score is (X/p-(1-X)/(1-p)); its variance is (1/[p(1-p)]).

2. Exponential MLE

For iid (Exp(\lambda)) with rate (lambda), find the MLE.

Solution

(ell=n\log\lambda-\lambda\sum X_i), so (hat\lambda=n/\sum X_i=1/\bar X).

3. Uniform endpoint

For iid (U(0,\theta)), find the MLE and explain why a score equation is unsafe.

Solution

The likelihood is ( heta^{-n}1\{\theta\ge X_{(n)}\}), decreasing on its support, so (hat\theta=X_{(n)}). Support depends on ( heta).

4. Invariance

If (hat\lambda) is the exponential-rate MLE, find the MLE of the mean (mu=1/\lambda).

Solution

MLE invariance gives (hat\mu=1/\hat\lambda=\bar X).

5. Unbiased endpoint estimate

Bias-correct (X_{(n)}) to estimate ( heta) under (U(0,\theta)).

Solution

Since (E[X_{(n)}]=n\theta/(n+1)), use ((n+1)X_{(n)}/n).

Problems 6-8 - Integration Problems
6. Normal information

For (N(\mu,\sigma^2)) with known (sigma^2), find (I_n(\mu)) and the Cramér–Rao bound.

Solution

(I_n=n/\sigma^2), so every unbiased estimator has variance at least (sigma^2/n); (ar X) attains it.

7. Delta-method rate

If (sqrt n(\bar X-1/\lambda)\Rightarrow N(0,1/\lambda^2)), find the asymptotic law of (1/\bar X).

Solution

For (g(x)=1/x), (g'(1/\lambda)=-\lambda^2). Thus (sqrt n(hat\lambda-\lambda)\Rightarrow N(0,\lambda^2)).

8. Sufficiency by factorization

Show (sum X_i) is sufficient for the exponential rate.

Solution

The joint density is (lambda^ne^{-\lambda\sum x_i}\prod1\{x_i\ge0\}), a parameter-dependent function of the sum times a parameter-free factor.

Problems 9-10 - ISI-Style Challenge
9. MSE tradeoff

For estimator (T) with bias (b(\theta)), state and prove the MSE decomposition.

Solution

Expand (T-\theta=(T-E T)+b). The cross term vanishes, giving (MSE(T)=Var(T)+b(\theta)^2).

10. Nonregular faster rate

For (U(0,\theta)), show (P(n(\theta-X_{(n)})/\theta>t)\to e^{-t}).

Solution

The probability equals (P(X_{(n)}<\theta(1-t/n))=(1-t/n)^n\to e^{-t}). The endpoint has (n), not (sqrt n), scaling.
