Core Pattern

Use one indicator per local event; classify overlapping pairs before computing variance.

Problems 1-5 - Concept Builders
1. Adjacent equal letters

In an iid binary string of length (n), find the expected number of equal adjacent pairs.

Solution

Each of (n-1) pairs is equal with probability (1/2), so the mean is ((n-1)/2).

2. Empty seats

Place (m) people independently into (n) seats. Find the expected empty-seat count.

Solution

(n(1-1/n)^m).

3. Random graph wedges

Find the expected number of two-edge paths on three specified vertices in (G(n,p)).

Solution

Each triple supports three choices of center, hence (3\binom n3p^2).

4. Pair collisions

Among (m) uniform labels from ([n]), find the expected equal-pair count.

Solution

(\binom m2/n).

5. Positive second moment

State the second-moment lower bound for (P(X>0)).

Solution

(P(X>0)\ge E[X]^2/E[X^2]).

Problems 6-8 - Integration Problems
6. Variance of collisions

Show distinct collision-pair indicators are pairwise independent and find (Var(C)).

Solution

Even overlapping pairs have joint probability (1/n^2); hence (Var(C)=\binom m2(1/n)(1-1/n)).

7. Coupon threshold

For (m=n\log n+cn), find the limiting expected number of missing coupons.

Solution

(n(1-1/n)^m\to e^{-c}).

8. Overlap graph

For triangle indicators in (G(n,p)), identify which pairs can have nonzero covariance.

Solution

Only triangles sharing an edge; disjoint triangles or those sharing one vertex use disjoint edges.

Problems 9-10 - ISI-Style Challenge
9. Triangle variance order

Give the two contributions to (Var(X)) for triangle count.

Solution

Individual terms contribute order (n^3p^3); edge-sharing pairs contribute order (n^4(p^5-p^6)).

10. Isolated-vertex threshold

For (p=(\log n+c)/n), find the limiting expected isolated-vertex count.

Solution

(n(1-p)^{n-1}\to e^{-c}).

Answer Summary

Use linearity for means and overlap classification for second moments.
