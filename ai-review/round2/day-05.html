AIR2-05-R0

Draw a chain, a fork and a collider from memory. For each, describe what observing its middle node changes. Use “graph guarantees independence” rather than claiming every open path produces dependence.

Does blocking one route block all the routes?

A Bayesian network represents a joint probability as one conditional distribution per variable, given its parents. To test a graph-implied conditional independence, inspect every undirected path between the two variables. A chain or fork is blocked by observing a middle non-collider. A collider, where two arrowheads meet, blocks a path unless the collider or a descendant is observed. Independence is guaranteed when all paths are blocked. An open path only removes that guarantee; special probability values can still produce independence.

Follow one complete example

In A→B→D and A→C→D, observing B blocks the first route from A to D. The route through C remains open. Observing both B and C blocks both. Looking at only one of the two routes would give the wrong conclusion.

AIR2-05-W1

In A←B→C, with no other edges, what happens after B is observed?

Worked check · open after your attempt

The fork is blocked, so the graph guarantees A and C independent given B.

If this step was difficult

Draw paths without arrow direction first, then classify each middle node using the arrowheads.

How many probabilities must we actually specify?

For a variable with r possible values, each conditional row has r−1 free numbers because the row sums to one. The number of rows is the product of its parents’ numbers of possible values. Roots have one row. Count one variable at a time before adding. This counts unrestricted conditional tables, not a model with extra parameter sharing.

Follow one complete example

A binary root U needs1 free number. A three-valued root V needs2. A binary child W with both parents has2×3=6 rows and1 free number per row. Total1+2+6=9.

How do the pieces fit together?

Every problem asks you to make an object you can reason with: a frontier, a game tree, a truth assignment, a path in a network or a probability table. The method then tells you which change is allowed. A final check asks whether the result answers the original question: cheapest route, forced conclusion or normalized probability. Learning the name of a method helps only when you can make and check those steps yourself.

Question and assumptions
  → representation: frontier / tree / assignment / network / factor
  → choose a rule and explain why it fits
  → carry out one justified step at a time
  → check cost, bound, truth or normalization
  → fresh problem without help
  → delayed recall and unfamiliar transfer
