AIR2-07-R0

Without notes, explain what rejection sampling discards, what likelihood weighting fixes, and which variables Gibbs sampling is allowed to update.

What should count in the denominator?

Rejection sampling draws complete assignments from the prior network and keeps only those matching the evidence. Estimate a conditional probability using only accepted samples. Likelihood weighting fixes evidence values instead of resampling them, and weights each sampled assignment by the probabilities of those evidence values given their sampled parents. Then the denominator is total weight. These procedures estimate the same posterior using different bookkeeping.

Follow one complete example

If200 prior draws contain8 evidence matches and3 of those also satisfy the query, rejection gives3/8, not3/200. If three weighted samples have query values1,0,1 and weights0.2,0.6,0.1, likelihood weighting gives0.3/0.9=1/3. The number of rows alone is not the correct denominator.

AIR2-07-W1

If evidence probability is0.002, how many matches do you expect in5000 prior draws? Is that count guaranteed?

Worked check · open after your attempt

Expected10; not guaranteed. Realized count is random.

If this step was difficult

Label each sample accepted/rejected or write its weight before calculating a proportion.

Why is a Gibbs update local?

Gibbs sampling keeps a current assignment for every variable. Evidence values remain fixed. One non-evidence variable at a time is redrawn conditional on all the others. In a Bayesian network, only its own conditional factor and its children’s factors depend on its proposed value. The other factors cancel when the candidate weights are normalized. This explains the Markov blanket rule rather than treating it as a list to memorize.

Follow one complete example

In A→B→C with B=b fixed, an update of A uses weights P(A=a)P(B=b|A=a). The factor P(C|B=b) is the same for every candidate a and cancels. B is never resampled because it is observed. If P(A=1)=0.5 and likelihoods for B=b are0.6 versus0.2, weights0.3 and0.1 give P(A=1|others)=0.75.

AIR2-07-W2

If B instead were unobserved and we updated B with A,C fixed, which factors would determine the two weights?

Worked check · open after your attempt

P(B=b|A)P(C|B=b), one weight for each candidate b, then normalize.

If this step was difficult

Write the full joint factorization and cross out factors that do not change with the variable being updated.

How do the pieces fit together?

Every problem asks you to make an object you can reason with: a frontier, a game tree, a truth assignment, a path in a network or a probability table. The method then tells you which change is allowed. A final check asks whether the result answers the original question: cheapest route, forced conclusion or normalized probability. Learning the name of a method helps only when you can make and check those steps yourself.
