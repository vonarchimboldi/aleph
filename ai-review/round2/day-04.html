AIR2-04-R0

Without notes, write when P→Q is false. Explain what a counterexample to entailment must make true and what it must make false.

How can one small example defeat a large claim?

An entailment says every interpretation satisfying the premises also satisfies the conclusion. To disprove it, find one interpretation where all premises hold and the conclusion fails. An implication P→Q is false only when P is true and Q is false. It does not say that Q can happen only because of P.

Follow one complete example

“If the alarm is armed, the light is on. The light is on. Therefore the alarm is armed.” Set armed=false and light=true. Both premises hold while the conclusion fails. In contrast, if the light is off, an armed alarm would contradict the implication, so the alarm must be unarmed.

AIR2-04-W1

If P→Q and ¬Q are true, can P be true?

Worked check · open after your attempt

No. P=true would force Q=true, contradicting ¬Q.

If this step was difficult

Try the four truth assignments for P,Q. Cross out any row violating a premise.

Can everyone have a helper without sharing the same helper?

In a finite group, ∀x∃y R(x,y) means each person x has at least one suitable y; the choice may depend on x. In ∃y∀x R(x,y), one y has to work for everybody. Quantifiers therefore describe who gets to choose first. To negate “every person has some helper,” we need one person with no helper: ∃x∀y ¬R(x,y).

Follow one complete example

For two people a,b, let R mean “is the same person as.” Each person has someone identical to themself, so ∀x∃y R holds. No single person is identical to both, so ∃y∀x R fails.

AIR2-04-W2

If R(x,y) means x<y on the integers, does ∀x∃y R hold?

Worked check · open after your attempt

Yes. For every chosen x, take y=x+1. There is no single integer larger than all integers.

If this step was difficult

Write a two-row table showing which y works for each x before manipulating symbols.

How do the pieces fit together?

Every problem asks you to make an object you can reason with: a frontier, a game tree, a truth assignment, a path in a network or a probability table. The method then tells you which change is allowed. A final check asks whether the result answers the original question: cheapest route, forced conclusion or normalized probability. Learning the name of a method helps only when you can make and check those steps yourself.

Question and assumptions

  → choose a rule and explain why it fits
  → carry out one justified step at a time
  → check cost, bound, truth or normalization
  → fresh problem without help
