What the concept does

A search problem needs a state, legal successor actions, a start, a goal test and a path cost. BFS expands the shallowest frontier state; DFS follows a deepest branch; uniform-cost search (UCS) expands the state with smallest cumulative cost g. BFS minimizes edge count and is cost-optimal when edge costs are equal. UCS is cost-optimal under the usual positive-cost conditions, when the goal is accepted on removal from the priority queue. State whether you use tree search or graph search, how repeats are handled, and how ties are broken before tracing.

A worked example

Let S→A cost 1, S→G cost 5, and A→G cost 1. BFS reaches G at depth one, costing 5. UCS pops S, then A with g=1, then G with improved g=2. The cheapest path is not the shallowest path.

Independent problems

AI01-Q1

On that graph, list the UCS pop order and the final goal cost. Explain why stopping when G is first generated would be wrong.

Compare after attempting

S, A, G; cost 2. The first generated G has cost 5 but a cheaper frontier route remains.

AI01-Q2

A finite directed graph has a reachable cycle. Can DFS without a visited set run forever? What changes with a visited set?

Compare after attempting

Yes, an unfortunate successor order may loop forever. Graph DFS with a visited set examines finitely many states/edges and terminates; it still need not find a shortest path.

AI01-Q3

For a full binary search tree with root at depth 0 and every goal at depth 3, how many nodes does BFS pop before its first goal, assuming it tests goals on pop?

Compare after attempting

All 1+2+4 nodes at smaller depths, then the first depth-three node: 8 pops. Distinguish nodes generated from nodes popped.
