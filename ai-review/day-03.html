What the concept does

In a deterministic two-player zero-sum game tree, a MAX node chooses the largest child value and a MIN node chooses the smallest. Utilities must share one perspective, usually MAX’s. Alpha is the best lower bound MAX can already secure; beta is the best upper bound MIN can enforce. A branch may be pruned when it cannot improve an ancestor decision (α ≥ β). Child order changes the amount of pruning, not the exact minimax value.

A worked example

A MAX root has two MIN children L and R, visited left to right. L has terminal values 3,5, so returns 3 and sets the root’s alpha to 3. R first reveals 2; its value can only stay at or below 2, so its remaining child is irrelevant to MAX’s choice and can be pruned.

Independent problems

AI03-Q1

Complete minimax when L has leaves 3,5 and R has leaves 2,9. Which branch is chosen?

Compare after attempting

L returns 3; R returns 2; root chooses L with value 3.

AI03-Q2

Trace left-to-right alpha–beta on that tree. Which leaf is not examined and why?

Compare after attempting

The leaf 9 under R is pruned. R already has beta 2 while root alpha is 3, so it cannot beat L.

AI03-Q3

Reverse the two leaves under R to 9,2. Does the value change? Does that pruning still happen?

Compare after attempting

The value stays 3. Seeing 9 first does not allow the cutoff; both R leaves must be examined in this order.
