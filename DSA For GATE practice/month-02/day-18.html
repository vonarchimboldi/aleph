Killer application: k-way merge

Session budget

0–10 recall · 10–25 baseline and choice · 25–45 primitive · 45–70 application and tests · 70–85 analysis/GATE · 85–90 exit note

One main task. Stop at 90 minutes and record partial work; optional extensions stay within the session.

Build the primitive

Keep one unconsumed head per nonempty sorted source in a heap; include a source tie-breaker.

Apply it

Merge k sorted arrays or iterators; optional: return a lazy iterator instead of a materialized result.

Explain why it works

The heap contains the smallest unconsumed candidate from every unfinished source.

Analyze the costs

O(k+N log(k+1)) time including source setup; O(k) auxiliary heap space, plus O(N) output if materialized.

Test the boundaries

Empty sources, all sources empty, equal values from different sources, uneven source lengths.

GATE practice

Original NAT: bound heap size and distinguish auxiliary space from returned output.
