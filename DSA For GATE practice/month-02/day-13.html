Build the primitive

Implement linear probing with EMPTY/OCCUPIED/DELETED states; bound a probe by table capacity.

Apply it

Repair lookup after deleting a colliding key; optional transfer: rehash a small table into doubled capacity.

Explain why it works

Only EMPTY terminates an unsuccessful search; DELETED preserves the probe chain.

Analyze the costs

O(1) expected operations only with appropriate hashing and controlled load/tombstones; O(n) worst case. A rebuild costs O(n) expected under the same assumptions.

Test the boundaries

Delete middle of cluster, wrap-around, full table, updating a key beyond a tombstone.
