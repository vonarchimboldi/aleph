Reversal without losing nodes

Session budget

0–10 recall · 10–25 baseline and choice · 25–45 primitive · 45–70 application and tests · 70–85 analysis/GATE · 85–90 exit note

One main task. Stop at 90 minutes and record partial work; optional extensions stay within the session.

Build the primitive

Implement iterative reversal with prev, curr and saved next.

Apply it

Reverse a singly linked list in place; optional transfer: reverse a specified prefix.

Explain why it works

prev is the reversed processed prefix; curr starts the untouched suffix; their nodes partition the original list.

Analyze the costs

O(n) time, O(1) auxiliary space; no recursive call stack.

Test the boundaries

Empty, singleton, two nodes; verify no node loss, duplication or cycle.

GATE practice

Original pointer-state MSQ: identify which update order loses the suffix.
