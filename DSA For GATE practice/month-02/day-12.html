Hash maps for lookup and counting

Session budget

0–10 recall · 10–25 baseline and choice · 25–45 primitive · 45–70 application and tests · 70–85 analysis/GATE · 85–90 exit note

One main task. Stop at 90 minutes and record partial work; optional extensions stay within the session.

Build the primitive

Implement a complement lookup; optional frequency-map variation.

Apply it

Find two distinct indices whose values sum to a target without sorting.

Explain why it works

Before processing index i, the map contains usable indices strictly before i.

Analyze the costs

Expected O(n) time and O(n) space under hashing assumptions; pathological lookup can make total O(n^2).

Test the boundaries

Duplicate values, same value needed twice, no pair, negative values.

GATE practice

Original MSQ: lookup before insert vs insert before lookup; compare sorting-plus-two-pointers.
