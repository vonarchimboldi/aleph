# GATE DA Data Structure Coverage

Checked against the [official GATE 2027 DA syllabus](https://gate2027.iitm.ac.in/static/doc/GATE2027_Syllabus/DA_GATE2027_Syllabus.pdf) on October 1, 2026. This map covers the programming/data-structures/algorithms section, not the entire DA examination.

| Requirement or extension | Placement | Boundary |
|---|---|---|
| Python programming | Every Month 2 lab | Primary practice language |
| Stacks | Days 1–3 and 5 | ADT, implementation, nesting, monotonic candidates, amortization |
| Queues | Days 4–5 and 10 | Ring, two-stack and linked representations; deque operations |
| Linked lists | Days 6–10 and 15/20 | Singly/doubly linked, reversal, merging, cycles, sentinels |
| Hash tables | Days 11–15 | Chaining/probing, collisions, deletion, growth, expected bounds |
| Trees | Dedicated Month 3 track remains required | Month 2 heap indexing is a bridge, not full tree coverage |
| Linear/binary search and named sorting algorithms | Existing Month 1 track | Retrieve when comparing representation and costs; heapsort is an extension |
| Graph theory, traversals and shortest path | Month 4 track remains required | Queue/stack/priority-queue applications prepare these algorithms |
| Heaps/priority queues | Days 16–20, requested extension | Not named separately in DA’s data-structure list; valuable for interviews and graph frontiers |

Dedicated future tree coverage should include representations, recursive/iterative traversals, BST search/insert/delete and height-dependent costs. Graph work must revisit BFS/DFS and shortest-path assumptions. This month does not claim that those future blocks are already completed or scheduled in detail.
