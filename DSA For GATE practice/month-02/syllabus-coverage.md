# GATE DA Data Structure Coverage

Scope follows the [official GATE 2027 DA syllabus](https://gate2027.iitm.ac.in/static/doc/GATE2027_Syllabus/DA_GATE2027_Syllabus.pdf), checked October 1, 2026. All five agreed Month 2 structures are introduced in Week 1; the following three weeks apply them.

| Requirement or extension | Introduction | Deeper application |
|---|---|---|
| Python | Every foundation lab | All application sessions |
| Stack | Day 1 | Days 6–8; nesting, monotonic candidates, transfer accounting |
| Queue and deque | Day 2 | Days 8 and 19; two-stack queue and window maximum |
| Linked lists | Day 3, singly linked plus doubly linked diagram | Days 9–11, 15 and 20; reversal, merging, cycles, LRU |
| Hash tables | Day 4, chaining | Days 12–15; lookup, probing/deletion, prefix counts, LRU |
| Heap/priority queue, requested extension | Day 5 | Days 16–18 and 20; heapify, heapsort, top-k, merge frontier |
| Trees | Dedicated Month 3 still required | Representations, traversals, BST operations and height-dependent costs |
| Search and named sorts | Existing Month 1 | Retrieval and comparisons; heapsort is an extension |
| Graph theory, traversals, shortest paths | Month 4 still required | This month prepares stack/queue/priority-queue operations |

Heaps are not named separately in DA’s list of basic structures. They are included by request and connect to priority queues. Their tree representation is a bridge to general trees, not a replacement for dedicated tree coverage. This document maps planned coverage, not verified learner mastery.
