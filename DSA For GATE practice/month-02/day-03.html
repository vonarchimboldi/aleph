Overview: linked lists

Session budget

0–10 recall · 10–25 representation · 25–55 core operations · 55–70 operation-log tests · 70–85 analysis/GATE · 85–90 exit note

One main task. Stop at 90 minutes and record partial work; optional extensions stay within the session.

Build the primitive

Implement Node, traversal, prepend, append with tail and one deletion case; finish empty/head/tail cases during the operation-log block. Preview doubly linked representation.

Apply it

Replay insert/delete operations on a singly linked list; diagram the extra prev links in a doubly linked list.

Explain why it works

Every live node is reachable exactly once; tail.next is None; empty head and tail agree.

Analyze the costs

Search/delete by value O(n); prepend and append with tail O(1); deleting a known node still needs its predecessor in a singly linked list.

Test the boundaries

Empty list, deleting head/tail, one node, missing key.

GATE practice
