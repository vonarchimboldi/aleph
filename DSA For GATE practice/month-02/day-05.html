Overview: heaps and priority queues

Session budget

0–10 recall · 10–25 representation · 25–55 core operations · 55–70 operation-log tests · 70–85 analysis/GATE · 85–90 exit note

One main task. Stop at 90 minutes and record partial work; optional extensions stay within the session.

Build the primitive

Implement sift_up, sift_down, push, peek and pop in a zero-indexed array; do not call heapq yet.

Apply it

Replay min-priority requests with push/pop; contrast FIFO order, sorted order and heap order.

Explain why it works

Every parent is <= its children; after a local repair only the repair path may temporarily violate heap order.

Analyze the costs

O(log n) comparisons/moves per push/pop; peek O(1). Dynamic-array resizing makes push O(log n) amortized overall, with occasional O(n) allocation work.

Test the boundaries

Empty pop, one child, equal priorities, ascending/reversed inserts.

GATE practice

Original heap-array MSQ; end the week by choosing between all five structures for five small tasks.
