Bottom-up heapify and heapsort

Session budget

0–10 recall · 10–25 baseline and choice · 25–45 primitive · 45–70 application and tests · 70–85 analysis/GATE · 85–90 exit note

One main task. Stop at 90 minutes and record partial work; optional extensions stay within the session.

Build the primitive

Extend Day 5 sifts with bottom-up heapify; adapt comparison for an in-place max-heapsort.

Apply it

Sort an array by moving the maximum to a growing sorted suffix and repairing the reduced heap.

Explain why it works

Active prefix is a max-heap; suffix is sorted and contains the removed maxima.

Analyze the costs

Heapify O(n) via node-height counting; heapsort O(n log n), O(1) auxiliary space with iterative sifts; normally unstable.

Test the boundaries

Duplicates, already sorted, reverse sorted, empty, one element.

GATE practice

Original NAT: compare n repeated insertions with bottom-up heapify and justify the height-sum bound.
