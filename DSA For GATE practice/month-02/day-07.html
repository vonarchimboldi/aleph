Monotonic stack

Session budget

0–10 recall · 10–25 baseline and choice · 25–45 primitive · 45–70 application and tests · 70–85 analysis/GATE · 85–90 exit note

One main task. Stop at 90 minutes and record partial work; optional extensions stay within the session.

Build the primitive

Implement unresolved-index stack with explicit strict-greater comparisons.

Apply it

For every array position, return the index of its next strictly greater value, or -1.

Explain why it works

Stack indices increase; their values are non-increasing; popped indices receive their first greater successor.

Analyze the costs

O(n) aggregate time: each index is pushed once and popped at most once; O(n) space.

Test the boundaries

Increasing, decreasing, all equal, repeated peaks.

GATE practice

Original NAT: count pushes/pops on a decreasing then increasing sequence; distinguish nested loops from quadratic work.
