Sentinels and merging lists

Session budget

0–10 recall · 10–25 baseline and choice · 25–45 primitive · 45–70 application and tests · 70–85 analysis/GATE · 85–90 exit note

One main task. Stop at 90 minutes and record partial work; optional extensions stay within the session.

Build the primitive

Build a dummy-head merge and reconnect existing nodes.

Apply it

Merge two sorted linked lists without allocating a node for every output entry.

Explain why it works

The output prefix is sorted and complete for all consumed nodes; both remaining suffixes stay sorted.

Analyze the costs

O(n+m) time, O(1) auxiliary space when reusing nodes, excluding a constant dummy node.

Test the boundaries

One empty input, equal values, uneven lengths, tail attachment; inputs are disjoint acyclic lists.

GATE practice

Original MCQ: stability with ties and the cost of finding an insertion position.
