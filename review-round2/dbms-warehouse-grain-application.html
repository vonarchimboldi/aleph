Warehouses: hierarchy direction, cuboids and group counts

Round two · relative week 2 · unit 6 · application · 90-minute proposed session

An aggregate describes a chosen level of detail

A sales fact might record a product, a day, a city and a quantity. Grouping by month combines several days. Grouping by country combines several cities. A hierarchy lists such levels, for example City→State→Country→ALL. ALL means the total across that dimension.

Moving down gives more detail

Changing Country to State gives a more detailed view. This operation is called drill-down. Changing State to Country combines detail and is called roll-up. Selecting one country is a different action, often called slicing. Ask what level of detail changes before naming the operation.

Follow a complete example

For two dimensions with 2 and 3 observed values and all combinations present, CUBE yields 6 detailed groups,2 first-dimension subtotals,3 second-dimension subtotals, and 1 grand total:12 rows. There are only 4 cuboids (grouping sets).

R2-DBMS-06-A-Q1 · Start with one small step

A sales cube changes geography from Country to City while preserving Product and Month. Is this roll-up, drill-down, slice or dice? Explain the level change.

Worked check · open after attempting

Drill-down: geography moves to a more detailed level. It need not select a single city.

Count aggregation choices separately from their rows

One choice of level for each dimension defines an aggregate view called a cuboid. If Time has four choices including ALL and Place has three, there are 4×3=12 cuboids. One cuboid can itself contain many rows. The number of cuboids is therefore different from the number of grouped rows.

R2-DBMS-06-A-Q2 · Put the pieces together

Dimensions Time has Day,Month,Year,ALL and Place has City,Country,ALL. How many cuboids are possible?

Worked check · open after attempting

4×3=12 choices of one level per dimension.

List the groups produced by CUBE

For two columns D1 and D2, CUBE includes detailed groups (D1,D2), D1-only groups, D2-only groups and one grand total. Count the rows in each part. A shortcut based on all possible pairs requires every pair to occur. For averages, keep the subgroup sums and counts so that a later roll-up can weight groups correctly.

R2-DBMS-06-A-Q3 · Use the idea in an exam-style problem

Two dimensions have 3 and 4 distinct values, with every pair observed. How many cuboids does CUBE(D1,D2) use, and how many output rows?

Worked check · open after attempting

4 cuboids; rows 12+3+4+1=20. They are different counted objects.

How the ideas connect

Count choices of aggregation level separately from rows inside a cuboid; drilling down changes resolution rather than filtering an arbitrary subset.

State one fact row’s grain. → Name the hierarchy level before and after an operation. → Count cuboids by independent level choices. → For CUBE row counts, sum the sizes of each grouping set.

If a problem was difficult

  • Confusing the number of cuboids with the number of output rows
  • Forgetting ALL
  • Adding averages without group sizes
