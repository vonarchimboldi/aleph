Sorting: implementation traces, passes and inversions

Round two · relative week 1 · unit 5 · application · 90-minute proposed session

Choose exactly what you will count

Sorting puts values in order. A key comparison asks how two values compare. A swap exchanges two values. A shift copies a value to a neighboring position. These actions have different counts. Write the question’s counting rule above your trace. Unless asked otherwise, keep loop-bound tests separate from comparisons between values.

Insertion sort grows an ordered prefix

After each insertion-sort iteration, the processed part at the left is sorted. Save the next value as the key. Move larger earlier values one position right until the key can be placed. With the condition earlierValue>key, equal values do not move past one another. This preserves their original order, a property called stability.

Follow a complete example

In insertion sort on [1,3,2], comparing 3>2 causes one shift; comparing 1>2 is false and stops the scan. Counting only key comparisons gives 3 overall: one during insertion of 3, then two during insertion of 2.

R2-DSA-05-A-Q1 · Start with one small step

List the inversion pairs in [3,1,2]. What is the minimum number of adjacent swaps needed to sort it?

Worked check · open after attempting

Pairs (3,1),(3,2); two adjacent swaps.

Bubble sort fixes values at the far end

In a left-to-right bubble-sort pass, compare neighboring values and exchange them when they are out of order. The largest value in that pass reaches the right end. A version that always completes every pass can perform more comparisons than a version that stops after a pass with no swaps. State which version you are using before claiming an exact count.

R2-DSA-05-A-Q2 · Put the pieces together

Trace the first two outer iterations of insertion sort on [4,2,3,1]. Give the array after each and total element shifts.

Worked check · open after attempting

[2,4,3,1], then [2,3,4,1]; shifts 1+1=2.

Use inversions to explain adjacent swaps

An inversion is a pair of positions whose earlier value is larger than the later value. Equal values do not form an inversion. Swapping an out-of-order neighboring pair removes exactly one inversion. Therefore a sorting method using only those swaps needs one swap per original inversion. This explains a count that a long trace might otherwise obscure.

R2-DSA-05-A-Q3 · Use the idea in an exam-style problem

Compare fixed-pass bubble sort (n−1 passes, inner lengths n−1,n−2,…,1, no early exit) with standard insertion sort (shift while a[j]>key). On [1,2,4,3], count key comparisons and swaps/shifts.

Worked check · open after attempting

Bubble:6 comparisons,1 adjacent swap. Insertion:1+1+2=4 key comparisons,1 shift. Do not count index tests.

How the ideas connect

Knowing Θ(n²) does not determine exact comparisons, swaps, shifts or the array after a stated number of passes.
