Preprocessing: formulas, reference statistics and information loss

Round two · relative week 2 · unit 7 · application · 90-minute proposed session

A transformation changes how values are represented

Suppose two columns use very different units or ranges. Rescaling can make their values easier to compare or use in a model. Different transformations answer different questions. Write the chosen formula before substituting any numbers.

A z-score measures distance from the mean

Subtract the reference mean from the value. Divide the result by the reference standard deviation. The answer tells you how many reference standard deviations the value lies above or below the mean. A negative answer means below the mean. The standard deviation must be positive for this division.

Follow a complete example

For reference mean 50 and standard deviation 10, a value 65 has z-score(65−50)/10=1.5. This says 1.5 reference standard deviations above the mean; it is not a percentile or a[0,1] scale.

R2-DBMS-07-A-Q1 · Start with one small step

Reference mean 20, standard deviation 4; compute the z-score of 26 and interpret its sign.

Worked check · open after attempting

1.5; the value is above the reference mean.

Min–max scaling uses a different reference

Subtract the reference minimum. Divide by reference maximum minus reference minimum. Values between those two reference bounds map to 0 through 1. A later value outside the reference range can map outside 0 through 1. That result does not by itself show an error. A zero reference range needs separate handling.

R2-DBMS-07-A-Q2 · Put the pieces together

Reference minimum 10, maximum 30; min–max scale a new value 35. Is the result necessarily an error?

Worked check · open after attempting

(35−10)/(30−10)=1.25. A new input outside the reference range can legitimately map outside[0,1].

Some transformations lose detail

Binning replaces an exact value with an interval label. Define which bin includes each boundary. Many distinct values can receive the same label, so the label usually cannot recover the original value. By contrast, an exact z-score with known mean and positive standard deviation can be reversed using x=mean+standardDeviation×z. Numerical rounding can still lose precision.

R2-DBMS-07-A-Q3 · Use the idea in an exam-style problem

A column has mean 80, standard deviation 12, min 20,max 140. Compute both z-score and min–max value for 98; identify which statistics each uses.

Worked check · open after attempting

z=(98−80)/12=1.5; min–max=(98−20)/(140−20)=0.65.

How the ideas connect

A transformation’s name, reference parameters and information-loss assumptions determine what can be computed and what can be recovered.

Name the transformation before substituting. → Use only the stated reference statistics. → Keep units and denominator visible. → Check interval endpoints and invertibility separately.
