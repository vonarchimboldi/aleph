Python objects, scope and simultaneous updates

Round two · relative week 1 · unit 1 · application · 90-minute proposed session

A name points to an object

Think of a Python list as a container holding values. A variable such as a is a name that points to that container. The statement b=a gives the same container another name. It does not copy the contents. If an operation changes the container, both names see that change.

Changing a list and replacing a name are different actions

Start with a=[1] and b=a. The statement a.append(2) changes the shared list, so both names now see [1,2]. Start again. The statement a=a+[2] first creates a new list. It then makes a point to the new list. The name b still points to the old [1]. Draw two containers to check this.

Follow a complete example

With a=[1]; b=a; a=a+[2], the concatenation creates a new list. Therefore a is [1,2], b remains [1]. Replacing the last statement by a.append(2) would mutate the shared object, making both names see [1,2].

R2-DSA-01-A-Q1 · Start with one small step

a=[2]; b=a; c=a[:]; b.append(5). Give a,b,c and identify the shared object.

Worked check · open after attempting

a=b=[2,5], c=[2]. a and b name one list; c names a copy.

The method append adds its argument as one new element. The method extend takes each element from its argument and adds those elements separately. For example, appending [2,3] creates a nested list element, while extending by [2,3] adds two numbers.

Some objects survive between calls

A default list in a function definition is created when Python defines the function. Later calls that omit that argument use the same list. A list created inside a function is different: each execution creates a new one. When an inner function continues to use an outer function’s list, it keeps a reference to that list. This is called a closure. Two separate calls to the outer function create separate lists.

R2-DSA-01-A-Q2 · Put the pieces together

Start a=[1]. Compare a.append([2,3]) with a.extend([2,3]), each on a fresh a.

Worked check · open after attempting

Append gives [1,[2,3]]; extend gives [1,2,3].

Follow the actual sequence of events

In a multiple assignment such as a,b=b,a, Python evaluates the right side before changing either name. The result is a swap. For exam code, keep a table of the names, the objects they refer to, and the contents after each statement. Explain each change before predicting the printed output.

R2-DSA-01-A-Q3 · Use the idea in an exam-style problem

def collect(v,L=[]): L.append(v); return L. Three separate print calls evaluate collect(4), collect(7), collect(9,[]). Give each printed line.

Worked check · open after attempting

[4]; [4,7]; [9]. The explicit empty list is a new argument; the default object persists across the first two calls.

How the ideas connect

A program’s output follows object identity and the actual order of evaluation, not what an operation sounds like.
