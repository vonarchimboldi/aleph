R2-DSA-01-T-Q1 · delayed

A={1,2}; B={2,3}; C={2,3,4}; execute A,B,C=A-B,B-C,C-A. Give the three results. Compare with executing those three assignments sequentially.

Worked check · open after attempting

Simultaneous: A={1}, B=∅, C={3,4}, because all right sides use the old sets. Sequentially: A={1}, B=∅, C={2,3,4}; the final difference uses the updated A and therefore retains 2.

R2-DSA-01-T-Q2 · transfer

def factory():
    x=[]
    def add(v):
        x.append(v)
        return x[:]
    return add
f=factory(); g=factory()
p=f(2); q=f(6); r=g(8)
Give p,q,r. Explain both shared closure state and snapshot copying.
Worked check · open after attempting

p=[2], q=[2,6], r=[8]. Calls through f share one captured list; g captures another. Returning x[:] produces independent snapshots.

Big picture

A program’s output follows object identity and the actual order of evaluation, not what an operation sounds like.
