Trees: reconstructing structure and proving bounds

Round two · relative week 1 · unit 6 · application · 90-minute proposed session

A tree records parent and child relationships

A rooted tree has a distinguished starting node, called the root. Each other node has one parent. A binary tree permits a left child and a right child at each node. A leaf has no children. A full binary tree requires each non-leaf node to have exactly two children.

A traversal chooses when to visit the root

Preorder visits the root, then the left subtree, then the right subtree. Inorder visits left subtree, root, right subtree. Postorder visits left subtree, right subtree, root. Apply the same rule again inside every subtree. These are rules about visiting a given tree, not rules that sort its labels.

Follow a complete example

Preorder A,B,D,C with inorder D,B,A,C gives rootA, left subtree rooted atB with left childD, and right childC. Its postorder is D,B,C,A.

R2-DSA-06-A-Q1 · Start with one small step

Give preorder, inorder and postorder for rootM with left childL and right childR.

Worked check · open after attempting

Preorder M,L,R; inorder L,M,R; postorder L,R,M.

Two sequences can reveal the missing structure

Assume labels are distinct. The first preorder label identifies the root. Find that label in inorder. Labels before it belong to the left subtree and labels after it belong to the right subtree. The number of left-subtree labels tells you how to split the remaining preorder sequence. Repeat this process on each smaller part.

R2-DSA-06-A-Q2 · Put the pieces together

Reconstruct preorder A,B,C,D and inorder B,A,D,C. Give postorder.

Worked check · open after attempting

RootA; leftB; rightC with leftD. Postorder B,D,C,A.

Read the assumptions before claiming uniqueness

Preorder alone leaves the side of a single child unknown. Preorder and postorder can also leave that ambiguity for an arbitrary binary tree. The full-tree assumption removes single-child cases. For counting questions, specify whether height counts edges or nodes. A height-three chain has four nodes when height counts edges.

R2-DSA-06-A-Q3 · Use the idea in an exam-style problem

Can preorder A,B and postorder B,A uniquely determine an arbitrary binary tree? What if every internal node has exactly two children?

Worked check · open after attempting

For an arbitrary tree, B can be left or right, so not unique. The two-node case violates the full-tree assumption; for a full binary tree with distinct labels, preorder plus postorder determines structure recursively.

How the ideas connect

Traversal sequences encode structural constraints; uniqueness requires the right assumptions, not just a memorized pair of traversals.

Locate the root using preorder or postorder. → Partition the inorder sequence into left and right subtrees. → Recurse on the corresponding subsequences. → Check each structural claim against the reconstructed tree or a counterexample.
