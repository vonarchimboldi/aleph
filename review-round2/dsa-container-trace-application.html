Stacks, queues and evolving control state

Round two · relative week 1 · unit 2 · application · 90-minute proposed session

Choose the end from which values leave

A stack removes the most recently added value. This rule is called last in, first out, or LIFO. A queue removes the value that has waited longest. This is first in, first out, or FIFO. In our drawings, a stack’s top is on the right. A queue’s front is on the left.

Separate the operation from its result

Suppose a stack contains [2,5]. Popping it removes 5 and leaves [2]. If the program stores that removed value in x, then x is 5. The container and the returned value are two different parts of the program’s state. A later statement can change either one.

Follow a complete example

Push 2, push 5, pop into x, then push x+1 gives stack [2,6] with top at the right. The removed value is 5; it is not still in the stack.

R2-DSA-02-A-Q1 · Start with one small step

Apply push(3),push(8),pop to an empty stack; apply enqueue(3),enqueue(8),dequeue to an empty queue. Give removed values and final contents.

Worked check · open after attempting

Stack removes 8 and leaves [3]. Queue removes 3 and leaves [8].

A deque lets you use both ends

A double-ended queue, or deque, supports insertion and removal at either end. Draw the full list after each operation. Label the left end as front and the right end as rear. Read removeFirst as an instruction to remove the current front, even if an earlier insertion changed which value is there.

R2-DSA-02-A-Q2 · Put the pieces together

A deque starts empty. insertLast(2), insertFirst(7), insertLast(9), removeFirst(), removeLast(). List both removed values and final deque.

Worked check · open after attempting

The removals are 7 then 9; final deque [2].

Control variables decide what happens next

A flag is an ordinary variable used to select between behaviors. If a statement changes the flag, later if statements in that same loop iteration see the new value. Trace a loop with columns for the container, the removed value, the flag and the running total. This makes an extra pop visible even when its value is discarded.

R2-DSA-02-A-Q3 · Use the idea in an exam-style problem

A stack contains [0,1,2,3,4] with top right. Repeatedly pop x; if x is odd and the stack is nonempty, pop one more value but do not add that extra value. Add x to a running total. Give the total and trace.

Worked check · open after attempting

Pop 4: total 4. Pop 3, discard 2: total 7. Pop 1, discard 0: total 8. Final total 8.

How the ideas connect

A container trace is a state machine: control variables and container contents jointly determine the next operation.

Choose a top/front convention. → Record state before and after each operation. → Update flags immediately. → Record popped values separately from the remaining container.
