Use a failed answer to locate a broken step.

A wrong B+ tree answer could reflect incorrect pointer/key layout, a rounding error or the wrong node type. A wrong DFS answer could reflect a misunderstood recursive return or an ignored neighbor order. Ask a smaller discriminating question before prescribing a lesson.

Three examples of the decomposition

2026 Q32 · B+ tree fanout

Prerequisites: bytes as units, integer capacity bounds, and the relationship between p child pointers and p−1 separators. Concept: the internal node layout, which differs from a leaf.

Draw p pointer slots and p−1 key slots. The capacity inequality is 10p + 11(p−1) ≤ 4096. Therefore 21p ≤ 4107, giving p = 195 at maximum. The 12-byte record pointer is irrelevant to this internal-node calculation.

Diagnostic: first ask how many keys accompany four child pointers; then ask for the byte inequality without solving it. This separates a structural misunderstanding from arithmetic trouble. A transfer check changes header size or asks about a leaf instead.

2026 Q40 · Reversed-graph reachability

Prerequisites: directed paths, reachability and reversing an edge. Concept: reversing a path reverses which endpoint can reach the other.

If DFS from v reaches u, there exists a path v→a→…→u. In the reversed graph it becomes u→…→a→v, so BFS from u reaches v. No traversal-order argument is needed.

Diagnostic: use the two-edge graph A→B→C. Ask for the reachable set and then the reverse path. Only afterward ask about DFS/BFS. A transfer check adds a cycle; the proof still works.

2026 Q51 · One output row per employee, one count per team

Prerequisites: grouping, keys, join multiplicity and column scope. Concept: computing at team grain, then returning to employee grain.

Group employees by TeamID to obtain one team count per team. Join those counts back to employees on TeamID. Grouping by unique EmpID instead produces groups of size one. Restricting a self-join to equal EmpID also collapses the count to one. An outer reference to a column omitted from a derived table is invalid.

Diagnostic: use a three-row table with two employees sharing a team. Ask what one output row represents before writing any SQL. A transfer check includes a single-member team and a different aggregate.

Build the skills before attempting the full problem
