Graphs: reachability, discovery order and counterexamples

Round two · relative week 1 · unit 7 · application · 90-minute proposed session

An edge describes an allowed step

A graph consists of vertices and edges. A directed edge A→B allows a step from A to B. It does not by itself allow a return step. A path is a sequence of allowed steps. Vertex B is reachable from A when some path leads from A to B.

Reachable vertices and visit order are different answers

Breadth-first search uses a queue and explores increasing distances in an unweighted graph. Depth-first search follows a branch and returns when that branch has no unvisited continuation. Both can find the same reachable vertices. Their discovery orders can differ. DFS order also depends on which neighbor it tries first.

Follow a complete example

If u reaches v via u→a→v, reversing every edge yields v→a→u. Thus reversing the graph reverses reachability direction. It does not generally reverse a traversal’s discovery list.

R2-DSA-07-A-Q1 · Start with one small step

For edges A→B and B→C, list vertices reachable from A in G and from A in the reversed graph, including the starting vertex.

Worked check · open after attempting

In G: A,B,C. In reversed G: A only.

Try DFS on A→B, A→C, B→D, with B tried before C. Visit A, then B, then D. D has no continuation, so return to B. B is finished, so return to A. A still has its untried neighbor C. The discovery order is A,B,D,C.

Reverse a path one edge at a time

Suppose A→B→C is a path. Reversing every edge produces C→B→A. This proves that if A reaches C in the original graph, C reaches A in the reversed graph. The proof does not need a particular visit order. Draw a small example before adding cycles or extra edges.

R2-DSA-07-A-Q2 · Put the pieces together

Vertices 0…6 have edges i→i+1 and i→i+2 when endpoints exist. DFS from 0 examines larger neighbors first. Give discovery order.

Worked check · open after attempting

0,2,4,6,5,3,1. Track returns from recursion rather than sorting the reachable set.

Use a shorter route to reject an impossible edge

If A–B–C–D is a shortest path, its length is 3. An extra A–C edge would provide A–C–D, of length 2. That contradicts the stated shortest distance. For a claim about every graph, try to prove it from a path or find a small counterexample. Keep discovery order, reachability and shortest distance separate while doing so.

R2-DSA-07-A-Q3 · Use the idea in an exam-style problem

Suppose u is visited by DFS from v in G. Which reachability claim is guaranteed in the reversed graph, and why?

Worked check · open after attempting

BFS from u in the reversed graph reaches v: reverse the original path v→…→u. The traversal algorithm affects order, not the reachable set.

How the ideas connect

Traversal order, reachable set and shortest-path distance answer different questions. Universal claims need proofs or small counterexamples.

Identify whether the question asks for order, a set, or distance. → Write the specified neighbor order before tracing. → Reverse an entire path to reason about a reversed graph. → Disprove a universal claim with the smallest legal graph.

If a problem was difficult

  • Assuming BFS and DFS have the same visitation order
  • Using numeric vertex order instead of adjacency order
  • Checking a necessary constraint as though it were sufficient
