R2-DSA-04-T-Q2 · transfer

Capacity 5, h(k)=2k mod 5, insert 1,6,11,2. Give slots and say whether the sequence exhibits a collision cluster.

Worked check · open after attempting

1→2,6→3,11→4,2→0. Yes: the initial hash for the first three is 2, and the cluster wraps for the last insertion.

Big picture

A hash value is a starting location; the collision policy determines the actual position and search path.

Calculate the initial hash. → Probe consecutive occupied slots, wrapping modulo capacity. → Maintain the table after every insertion. → Connect insertion to unsuccessful lookup under the stated probabilistic model.

Use the error to choose the next task

  • Writing the hash value as the final slot
  • Ignoring wraparound
  • Treating an expected bound as a worst-case guarantee
